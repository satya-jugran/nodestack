# 🛒 NodeStack E-Commerce React Demo

A modern, fast, full-featured retail storefront built with **React**, **Vite**, **Tailwind CSS**, and **`nodestack-client`**, connected directly to an embedded **NodeStack** backend.

---

## ⚡ Architecture & Capabilities Showcased

* 🌐 **Built-in Multi-App Architecture**: Shipped by default with the pre-seeded `ecommerce-demo` application alongside the clean `default` app.
* ⚡ **Embedded Serverless Lambdas (QuickJS-WASM)**:
  * `calculate-discount`: Realtime coupon & discount calculator (`SAVE20`, `WELCOME10`, `FLAT50`, `FREESHIP`, `VIP30`).
  * `validate-order`: Order line items, catalog pricing integrity, and address validation.
  * `update-inventory`: Direct stock decrementing in the SQLite database via `ctx.records`.
  * `generate-tracking-label`: Simulates carrier shipping label generation (`FedEx`, `DHL`, `UPS`) and delivery ETA.
  * `grant-loyalty-points`: Calculates VIP loyalty rewards based on order volume ($200+).
  * `send-order-notification`: Dispatches confirmation receipts and updates live order fulfillment status.
* 🔀 **NodeStack Flows Engine (State Machine)**:
  * **`OrderFulfillmentFlow`** (`eventTrigger: 'orders:create'`): Automated event-driven state machine that triggers on checkout, executes parallel branches for inventory and tracking, evaluates VIP tier status, and finalizes fulfillment.
  * **`CheckoutPromotionFlow`** (`triggerType: 'http'`): Step-function pipeline evaluating promo codes and unlocking bundle perks ($15 credit + premium packaging for carts $150+).
* 📡 **Realtime SSE Reactivity**: Listens to server change streams (`client.collection('products').subscribe('*')` and `client.collection('orders').subscribe('*')`) to update UI live when stock changes or when fulfillment assigns tracking numbers.
* 🔐 **Authentication**: User registration, login, JWT session management via `LocalAuthStore`, and **1-Click Demo Login** (`alex.vance@nodestack.dev`).
* 📦 **Product Catalog**: 20 pre-seeded products across 5 categories with SVG hero imagery, stock levels, and ratings.
* 💳 **Slide-Over Cart Drawer & Fast Checkout**: Promo code engine with interactive chips, free shipping meter ($100 threshold), and instant order placement.

## 🚀 Quick Start

### 1. Launch the Backend Server

From the root repository directory:
```bash
npm start
```
* **API**: `http://localhost:8090/api/`
* **Admin Dashboard & Visual Flow Designer**: `http://localhost:8090/_/`
  *(Switch to **E-Commerce Demo** in the top navigation bar to explore collections, lambdas, and visual state machines!)*

---

### 2. Launch the React Storefront

From the `examples/ecommerce-react` directory:
```bash
cd examples/ecommerce-react
npm run dev
```
Visit **`http://localhost:5173`** to test the storefront!

---

### 3. Testing the Capabilities

1. **Test Serverless Discount Lambda**:
   * Add any item to the cart.
   * Open the Cart Drawer.
   * Click chip **`SAVE20`** (or enter `WELCOME10`, `FLAT50`, `FREESHIP`).
   * Click **Apply**: the storefront invokes the backend lambda in real time and updates the total!
2. **Test Flow State Machine & Realtime Reactivity**:
   * Place an order.
   * NodeStack automatically triggers **`OrderFulfillmentFlow`** in the background!
   * Notice product stock levels decrement live on the storefront screen.
   * Open **My Orders**: view the carrier and tracking code generated by the Flow!
   * Open the NodeStack Admin UI at `http://localhost:8090/_/` $\rightarrow$ **Flows** tab $\rightarrow$ **Executions** tab to inspect the visual step diagram and execution timing!
